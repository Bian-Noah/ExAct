#       OpenVLA          : transformers==4.40.1    | torch==2.2.0      | numpy<2.0      | Python 3.10/3.11
#       两者在 transformers / torch / tokenizers / numpy 上版本交集为空。
#
# 【安装方法（按需分开安装）】
#   1. 决定用哪个 VLA 后端（当前默认 OpenVLA，见下方路线 B 块）。
#   2. 只保留对应块：用 OpenVLA → B 块保持取消注释、A 块保持注释；
#      切回 lerobot → 注释掉 B 块、取消 A 块注释（并注意 Python 需 >=3.12、
#      torch 需按 A 块注释里的命令另装 CUDA 版）。
#   3. pip install -r requirements.txt
#      如果同时取消 A、B 两块注释，pip 会报依赖冲突——这是预期的，不是 bug。
#
# 【Python / torch 说明】
#   - OpenVLA 路线：Python 3.10/3.11（torch 2.2.0 wheel 仅到 cp311）。
#   - lerobot 路线：Python>=3.12；torch 需先装 CUDA 版（见 A 块注释）。

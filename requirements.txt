# ============================================================================
# ExAct 依赖清单 —— 统一 pip 安装（Linux + CUDA + Python 3.12）
# ============================================================================
#
# 【安装顺序约定（重要）】
#   1. 先装 CUDA 版 PyTorch。lerobot 0.6.x 强制 torch>=2.7,<2.12、
#      torchvision>=0.22,<0.27。不要在下面的 requirements 里重复 pip install
#      torch/torchvision，否则会被覆盖为 PyPI 默认的 CPU/最新版：
#        pip install "torch>=2.7,<2.12" "torchvision>=0.22,<0.27" \
#            --index-url https://download.pytorch.org/whl/cu128
#      cu128 按显卡驱动可选 cu124/cu126，对照表见 https://pytorch.org/get-started/locally/
#   2. 再装本文件：pip install -r requirements.txt
#      此时 lerobot 看到 torch 已满足约束，不会重装。
#   3. pybullet 在 Python 3.12 上无预编译 wheel（PyPI 最新 3.2.7 仅到 cp311），
#      pip 会走源码编译，需要本机有编译工具链；cmake 由 lerobot 依赖自动带上。
#      编译耗时数分钟，属正常现象。
#   4. 装完跑 pip check 验证依赖闭环；缺啥补啥（普通 pip install，不要加
#      --no-deps，让 pip 自行协调传递依赖）。
#
# 【版本策略】
#   - lerobot：项目代码锁定语义 >=0.6（用到 0.6 引入的 make_pre_post_processors
#     API，0.4 无此入口；0.6.1 实测验证）。0.6.1 要求 Python>=3.12。
#   - torch / torchvision：不写在此文件（避免覆盖 CUDA 版），约束见第 1 步命令。
#   - 其余依赖不指定版本，由 pip resolver 统一协调；numpy 会被 lerobot 约束在
#     >=2.0,<2.3，无需手工处理。
# ============================================================================
